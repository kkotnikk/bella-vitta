# Bella Vitta

Site de moda feminina no atacado da Bella Vitta, no Pari, São Paulo.

## Estrutura

- `index.html`: conteúdo, estilos e interações.
- `assets/`: imagens editoriais em WebP.

## Visualizar

Abra `index.html` no navegador. Não exige instalação ou compilação.

## GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**.

As imagens são ilustrativas e podem ser substituídas pelas fotos originais das peças.
